"Preciso de um site ou de uma landing page?" É uma das perguntas mais comuns de quem tem clínica e quer começar a atrair pacientes pela internet. A resposta depende do momento do negócio.

## Landing page

É **uma única página**, com um objetivo: levar a pessoa a uma ação, como agendar uma consulta pelo WhatsApp. Ela apresenta a clínica, os tratamentos, quem atende e as dúvidas mais comuns, sem distrações.

**Vantagens**
- Mais rápida de construir e de manter.
- Objetiva: o visitante sabe o que fazer.
- Funciona bem para anúncios e para buscas locais.

**Limitações**
- Pouco espaço para muitos tratamentos ou profissionais.
- Menos páginas para o Google indexar.

## Site institucional

É um site com **várias páginas**: início, equipe, uma página para cada tratamento, blog, contato.

**Vantagens**
- Mais espaço para explicar cada tratamento em detalhe.
- Mais páginas para aparecer em buscas diferentes.
- Passa uma imagem mais completa.

**Limitações**
- Dá mais trabalho para construir e manter atualizado.
- Exige conteúdo de qualidade em cada página.

## Como decidir

- **Está começando, tem poucos tratamentos ou quer testar o interesse?** Comece por uma landing page.
- **Tem equipe grande, muitos tratamentos ou quer investir em conteúdo?** Vale um site com várias páginas e um blog.
- **Vai fazer anúncios?** A landing page é a escolha natural, porque cada anúncio pode levar para uma página focada.

## Os dois não competem

Uma landing page pode ser o primeiro passo e crescer depois para um site completo, aproveitando o que já foi feito. O importante é que, seja qual for a escolha, a página seja **rápida no celular, clara e com um caminho óbvio para marcar a consulta**.
